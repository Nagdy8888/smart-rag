# ADR: Vision captioning (v1 non-goal)

## Status

`proposed` / evaluation trigger only. V1 does **not** caption figures/charts/diagrams.

## V1 behavior

Material evidence only inside non-OCR images → explicit limitation notice (QT-MEDIA-*).

## Promotion trigger

Client funds governed vision captioning **and** signs quality/cost/privacy gates; then reopen this ADR with model, retention, and eval fixtures.
