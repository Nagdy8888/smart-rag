## Preconditions

- `P08-01` and `P08-02` provide approved primitives, shell, Auth, compatibility, and typed streaming/query clients.
- Real chat, diagnostics, document, table, graph, citation, feedback, quota, and audit contracts are available.
- Phase 7 mapping covers frames 04/05/06/07/09/10, the state gallery, and required gaps.

## Allowed outputs

- Production chat/test bench, document/upload/detail, structured-table, graph explorer, citation/source, inference, and feedback surfaces.
- Tests, frame/gap traceability, and documentation within this packet.

## Forbidden outputs

- Graph-only prose as answer evidence, BM25 snippets as authority, invented totals, mock diagnostics, or unauthorized graph/source metadata.
- Generated HTML porting, static readiness/quota values, fake success, unsafe markup, or unbounded graph/table rendering.
- Omission of required limitation, fallback, partial, degraded, or gap-fill states.

1. Implement frame 04's Auto-first shell, advanced manual modes, pipeline/inference/scope/citation patterns, source drawer, feedback, diagnostics, streaming, and route/limitation presentation.
2. Implement state-gallery families for verified, partial, refusal, contradictory authority, route correction, degraded service, reconnect, deadline, and fallback.

6. Fill absent BM25 projection/outage, deadline/partial, historical temporal route, figure/media, negation, full-summary, quota/quarantine, API version, graph backlog/fallback, `Graph Pending`, and authorized ACL-blindness states from real contracts.

## Acceptance checks

- Frame behavior is traceable and every required missing state has an approved primitive-based implementation.
- `Auto` is default; diagnostics distinguish requested/effective/corrected routes, dense+term BM25 degradation, Hybrid fallback, limitations, and partial readiness.
- Citations open authorized canonical sources; inference links cite atomic support; table results retain exact deterministic provenance.
- `Graph Pending` differs from authorized ACL blindness, and unauthorized actors receive no count, title, entity, relation, or source leakage.
- Upload/quarantine/quota/readiness/backlog/retry/version/anomaly/deletion journeys use real server state.

## Negative tests

- Exercise BM25 and LightRAG outage, deadline, route correction, insufficient evidence, uncovered summary, negation without closed-set proof, media-only evidence, historical relationship, duplicate submit, and reconnect.
- Forge source/run/document/graph access; test deleted/current-version changes and restricted-preview/download audit behavior.
- Inject hostile filenames, snippets, entities, relations, citations, table cells, and answer content; reject generated `innerHTML`.
- Attempt unbounded graph/table requests and client-calculated totals.

## Stop routes

- Stop when a required diagnostic/state lacks a real typed contract or canonical evidence resolver.
- Return authorization, provenance, quota, graph mapping, or route-semantics gaps to the owning phase without mock substitution.
